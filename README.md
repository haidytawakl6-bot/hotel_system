🏨 Hotel Management System

A simple Hotel Management System built using Python, Object-Oriented Programming (OOP), and Gradio.

📌 Project Description

This project is a simple hotel booking system that allows users to book rooms, complete the first day, and cancel bookings.

The system calculates the room price, total bill, discount, and refund according to the booking details.

✨ Features

* Book a hotel room
* Choose between Single and Double rooms
* Enter guest name and age
* Specify the number of days
* Automatically assign a room number
* Calculate the total bill
* Apply a 10% discount for stays of 3 days or more after completing the first day
* Complete the first day of the booking
* Cancel a booking
* Calculate the refund after cancellation

💰 Room Prices

Room Type	Price per Day
Single	$100
Double	$150

🛠️ Technologies Used

* Python
* Gradio
* Object-Oriented Programming (OOP)

▶️ How to Run

First, install the required library:

pip install -r requirements.txt

Then run the project:

python main.py

The Gradio interface will open in your browser.
